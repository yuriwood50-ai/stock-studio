# 스톡 스튜디오 (Stock Studio)

스톡 이미지 한 세트를 만드는 전 과정을 정리해 주는, **내 컴퓨터에서 도는** 제작 프로그램이에요. AI 활용 서비스 기획 실무 과정의 수업 프로젝트로 시작했어요.

## 목적

스톡 이미지는 낱장이 아니라 세트로 팔려요. 한 세트를 올리려면 소재 목록 짜기, 프롬프트 쓰기, 파일 이름 붙이기, 여백 자르기, 규격 확인을 열두 번쯤 반복해야 하고, 그 반복이 등록을 미루게 만들어요.
이 프로그램은 **사람이 판단할 곳(무엇을 만들지 · 목록 다듬기 · 결과 확인)만 남기고** 나머지 반복 작업을 맡아요. 어도비스톡과 미리캔버스 두 곳의 제출 조건을 겹쳐서 한 번에 맞춰요.

> 이번 범위에서는 이미지 생성 자체는 사람이 ChatGPT에서 받아 와요(구조에는 자동화 자리가 이미 있어요). 소재 목록 생성만 OpenAI 글자 모델이 맡아요.

## 사용 흐름

```text
 ① 입력          ② 목록           ③ 제작              ④ 완료
 만들 것 한 줄 ─▶ AI 가 소재 표 ─▶ 프롬프트 복사 ─▶ 받은 이미지 ZIP 올림 ─▶ 세트 폴더 + 체크리스트
 + 그림체 선택     사람이 다듬음     ChatGPT 에서 생성   자동 짝짓기 · 검사 · 정리
```

1. **입력** — 주제 한 줄과 그림체를 고릅니다.
2. **목록** — 소재 목록을 AI 가 뽑고 사람이 다듬습니다. 소재끼리 시점·재질·형태가 겹치지 않게 해요.
3. **제작** — 소재마다 조립된 프롬프트를 복사해 ChatGPT 에서 이미지를 만들고, 받은 파일(ZIP 포함)을 올려요. 나눠 받아도 돼요.
4. **완료** — 통과한 이미지만 이름 규칙대로 정리된 폴더가 만들어지고, 제외된 파일은 사유와 함께 `_제외` 에 남아요.

## 아키텍처

```text
 web/ (브라우저 화면 1~4)                server.js (로컬 HTTP 서버, 기본 포트 3900)
   화면은 규칙을 갖지 않고 ─ API ─▶     web/ 을 띄우고 브라우저를 자동으로 연다
   서버에 물어본다                       .env 의 API 열쇠는 서버만 읽는다 (화면·설정.json 으로 안 나감)
                                              │
                                              ▼
                              core/  ── 모든 규칙이 있는 단 하나의 장소 ──
                              (화면도, 배치 파일 build.js 도 같은 core/ 를 부른다)
```

**규칙이 한 곳에만 있다**는 것이 핵심 설계예요. 프롬프트 조립 규칙이 화면과 서버 두 군데 있으면 반드시 어긋나기 때문이에요. 파일 이름도 `core/이름.js` 하나에서만 만들어져서 프롬프트·안내 문구·실제 저장이 같은 이름을 써요.

| 모듈 (`core/`) | 역할 |
|---|---|
| `설정.js` | `설정.json` 읽기·쓰기. 두 플랫폼 조건인 고정 항목은 켤 때마다 제자리로 복구 |
| `AI.js` | OpenAI 연결(소재 목록 생성). 열쇠는 `OPENAI_API_KEY` 환경 변수로만 읽음 |
| `프롬프트.js` | 6줄 프롬프트 조립. 한 세트 안에서 바뀌는 건 소재 관련 2·3줄뿐 |
| `제작문구.js` | 화면 3 의 프롬프트 목록·파일 받기 문구 |
| `받은파일.js` | 화면 3 에서 올린 파일(ZIP 해제 포함)을 잠시 보관 |
| `짝짓기.js` | 받은 파일 ↔ 소재 목록 배정 (전체 다시 맞추기 / 새 파일만 추가) |
| `검사.js` | 통과 검사 19단계 (읽기·투명도·크기·잘림·크롭·용량…) |
| `유사도.js` | 32×32 회색조 지문으로 세트 안 비슷한 이미지 표시 (`_check`, 삭제하지 않음) |
| `픽셀.js` · `png청크.js` | 알파 기준 타이트 크롭, sRGB·120dpi 청크 부여 |
| `이름.js` | 세트번호·아이템번호·파일명 규칙 (`O03-01_스테이플러.png`) |
| `세트만들기.js` · `결과보기.js` | 결과 폴더 생성, 화면 4 용 폴더 읽기 |
| `목록읽기.js` | 투입 폴더의 `세트.txt` 읽기 |

### 결과 폴더 구조

```text
결과/O01_가을열매/
├─ 00_세트정보/세트.json
├─ 01_소재목록/목록.csv
├─ 02_프롬프트/O01-01_밤.txt …          (이미지와 같은 이름)
├─ 03_이미지/O01-01_밤.png … + _제외/
└─ 04_업로드준비/ 제목·키워드.csv · 제출 체크리스트.md · 미리캔버스만/
```

## 시작하기

요구사항: Windows, Node.js 24 이상, (소재 목록 AI 생성을 쓰려면) OpenAI API 키.

1. `.env.example` 을 `.env` 로 복사하고 `OPENAI_API_KEY=` 뒤에 키를 붙여넣어요. (`.env` 는 Git 에 올라가지 않아요.)
2. `실행.bat` 을 더블클릭해요. 처음에는 `npm install` 이 자동으로 돌고, 브라우저가 열려요.

화면 없이 폴더만 정리하고 싶다면: `투입/세트.txt` 에 세트 정보와 소재를 적고 `투입/이미지/` 에 받은 이미지를 넣은 뒤 `세트 정리.bat` 을 실행해요.

```bash
npm start         # 서버 실행 (실행.bat 과 같음)
npm run check     # 규칙이 계획서대로 도는지 점검 (점검.js)
npm run build     # 투입 폴더 → 결과 폴더 (세트 정리.bat 과 같음)
```

## 설정 (`설정.json`)

| 구분 | 내용 |
|---|---|
| 고정 | 생성 크기 2880×2880, sRGB, 120dpi, 최소 4MP·짧은 축 700px, 최대 용량 45MB 등 **두 플랫폼 조건** (바꿀 수 없음, 이유가 `고정_왜` 에 적혀 있음) |
| 조정 가능 | 여백px · 알파 임계값 · 유사도 기준 · 서버 포트 · 결과 폴더 · 프롬프트 문장 · AI 모델·한도 · 그림체 |

고친 뒤에는 프로그램을 다시 켜야 반영돼요. **API 열쇠는 `설정.json` 에 넣지 않아요.**
